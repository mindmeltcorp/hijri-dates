# Announced Ramadan dates

`ramadan.json` holds the first and last day of fasting for each Hijri year, as officially announced.

- `default`: the dates announced in Saudi Arabia.
- `regions`: countries (two-letter code) whose announced dates differ.

To update after an announcement, add one line per year: `"1448": ["first day", "last day"]` in `YYYY-MM-DD` form.
